# 조사 파이프라인 4

HTTP 403/404/429/5xx, 시간초과·DNS·TLS, CAPTCHA, 응답 크기, 다른 사이트 리다이렉트, JavaScript 렌더링/한도 초과를 분리해 SQLite와 보고서에 저장합니다. 같은 실행 중 중복 요청은 합치고 일시 오류만 제한 재시도합니다. 실패 URL·제공자는 원인별 다음 조사 시각까지 쉽니다. CAPTCHA·로그인·접근 차단을 우회하지 않습니다.

공식 API가 미설정이면 공개 HTML 검색 외에 Bing RSS·Google News RSS·공개 도구 목록을 후보 경로로 사용합니다. 공식 사이트 내부 링크·사이트맵과 12개 공식 요금 조사 목표도 검색 성공과 독립적으로 확인합니다. 404가 난 옛 행사 주소는 같은 공식 사이트의 공개 첫 화면에서 상세 링크를 다시 찾습니다.

공식 공개 페이지의 JavaScript 화면은 실행당 최대10회 브라우저로 읽고, 명확한 월간 요금 선택기만 선택합니다. 숨겨진 연간/월간 가격은 렌더링 근거에서 제외합니다. 정적 원문에 유효 근거가 있으면 선택적 렌더링 한도 초과 때문에 기존 근거까지 버리지 않습니다. 연간 요금은 표시된 연간 총액만 저장하며 월 환산 광고 금액을 곱해 총액을 만들지 않습니다.

신원·정기 가격 확인은 등록 목록 편입 기준입니다. 약정·지역·기능 동등성까지 검증됐다는 뜻은 아닙니다. 대안 비교는 별도로 정상 요금과 동일/상위 기능 조건을 만족해야 합니다. 보안·백업·음성·영상 제작·디자인·독서·개발 도구·학습·업무 자동화·호스팅 등 새 분류를 배포할 수 있습니다.

한국시간 매일01시 배포와 함께 새 서비스·분류·용도·별칭·설명이 확인되면 당일에도 증분 배포합니다. 앱은 실행·복귀·수동 갱신에서 반영하며 사용자 분류·이름 변경과 실제 비용 기록은 유지합니다.

Google/Naver 공식 API는 저장소 Secrets 설정 전에는 사용되지 않습니다. 대체 경로가 있어도 모든 사이트의 접근·가격 검증 성공을 보장하지 않습니다. 미확인 정보는 보류 상태와 실패 원인·다음 조사 시각으로 남깁니다.
