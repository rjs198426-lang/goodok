# 혜택 수집 갱신 개선 · 파이프라인 5

2026-11-11 공개 피드와 운영 SQLite 점검에서 작업은 실행되고 있었지만, 공개된 혜택 7개는 모두 10월 25~27일에 처음 발견된 캠페인이었습니다. 마지막 확인 시각이 바뀌어도 신규 혜택이 발견됐다는 뜻은 아니었습니다.

확인된 원인과 변경:

- Adobe 한국 약관의 `첫해`, `12개월 구독 약정`, `일에 종료됩니다` 표현을 읽지 못했습니다. 해당 문구와 명시된 시작·종료일을 해석합니다. 시작 전·종료 후 캠페인은 공개하지 않습니다.
- 로그인·회원가입 페이지가 공식 도메인이라는 이유로 검증 대기열에 남았습니다. 공식 사이트도 탐색용 페이지는 제외합니다.
- Bing의 `msockid` 추적 주소가 중복 후보를 만들었습니다. 캠페인·자격 조건 쿼리는 보존하고 추적 값만 제거합니다. 기존 원본 후보와 검증 이력은 삭제하지 않습니다.
- 오래된 일반 소개 페이지가 제한된 검증 횟수를 차지했습니다. 공식 행사 상세 URL을 우선하고 서비스별 검증 수를 제한합니다.
- 폭넓은 검색과 목록 조사가 공식 혜택 조회보다 먼저 브라우저 한도를 썼습니다. 알려진 혜택부터 확인합니다.
- Proton 공식 Black Friday 페이지의 플랜별 선결제·자동 갱신 가격을 분리하고, Lovable 공식 학생 할인은 학교·재학 인증과 무료 플랜 조건을 확인해 수집합니다. 명시되지 않은 종료일은 만들지 않습니다.
- 보고서에 신규·조건 변경·재확인 건수를 따로 기록합니다. 같은 캠페인의 단순 재확인은 신규로 세지 않습니다. 확인 시각이 같으면 종료일이 있는 캠페인, 한시 할인 순으로 우선합니다.

공식 확인 주소:

- https://www.adobe.com/kr/offer-terms/cc-full-special-offer-intro.html
- https://protonvpn.com/black-friday
- https://lovable.dev/students

기존 시간별 GitHub Actions와 공개 피드 주소를 그대로 사용합니다. 앱 2.1.4의 피드 형식과 호환되므로 이 변경에 APK 재설치는 필요하지 않습니다. 접근 차단과 미설정 Google/Naver 검색 API는 별도 진단 항목으로 유지하며, 조회 실패를 성공이나 신규 혜택으로 표시하지 않습니다.
