## 검증과 남은 운영 확인

- 앱 단위 테스트 48개, 백엔드 41개, 브라우저 회귀 10개 묶음 통과. 홈 6개 화면 크기, 추천 8개·혜택 4개와 긴 제목, 데이터 이전·복원·환불·예산·비교를 확인했다.
- Android release 빌드·전체 lint 통과(오류 0개, 경고 별도 기록). APK 버전·비디버그·이전 서명 호환·정렬·소스 자산 일치를 검사한다.
- 실제 기기/에뮬레이터에서 OCR 인식, 음성 제공자, 런처 위젯, 독립 저장 제공자, 금융 알림 수신, 재부팅·절전·권한 거부·앱 업데이트 후 알림/복원은 실행하지 못했다. 브라우저 모의 브리지는 이를 대체하지 않는다.
- 물리 기기 확인 순서: 기존 앱 백업 → 삭제 없이 업데이트 → 이전/신규 백업 복원 → 권한 거부·허용 → 테스트/3일·1일/미루기 알림 → 재부팅·절전 → 이미지/위젯/공유 → 자동 백업 두 사본 및 실패 시 이전 사본 유지.
- 실제 사용자 입력 시간 감소·OCR 정확도·알림 도착률·4주 유지율 수치는 아직 없다. 선택 로컬 지표로 실제 사용 후 평가할 수 있다.
- 브리핑의 은행 연동·공동 가계부·별도 웹 버전은 수요·연동 조건 확인 후 검토하는 항목으로 남긴다.

설치 파일은 한국어 인식 모델 포함으로 약 48MB이다. 기존 패키지 `kr.goodok.note`, 저장 키 `goodok-note-v1`, 백업 식별자/형식 버전, 업데이트 서명을 유지한다. 새 기능 자료는 2.0.0 이상에서 복원하는 것이 안전하다. 앱을 지우지 않고 업데이트하며 먼저 독립 백업을 권장한다.
