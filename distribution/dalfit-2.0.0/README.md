Android 8.0 이상, 약48MB. 휴대폰 브라우저에서 APK를 내려받아 설치하세요. 요청 시 해당 브라우저/파일 앱의 ‘이 출처 허용’을 켭니다. 기존 달핏을 삭제하지 않고 업데이트하며, 먼저 독립 백업을 권장합니다. Google Play에서 설치하는 버전은 아닙니다.

배포 도구의 요청 크기 제한 때문에 검증된 ZIP을 세 조각으로 보관합니다. 다운로드에는 위 APK 주소를 사용하세요. GitHub Actions가 세 조각의 전체 SHA-256과 APK SHA-256을 확인한 뒤 원래 서명된 파일 그대로 릴리스에 올립니다. 새 앱을 빌드하거나 서명 키를 저장하지 않습니다. 이미 같은 릴리스 파일이 있으면 해시를 대조하며 다른 파일로 덮어쓰지 않습니다.
