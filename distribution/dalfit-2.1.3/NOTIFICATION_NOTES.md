# 달핏 2.1.3 · 빌드 52 — 확인한 알림 닫기

2026-11-04 한국시간 기준.

- 알림 본문 또는 ‘결제 확인’을 누르면 그 알림의 태그와 번호로 알림창에서 제거합니다. 다른 항목의 알림은 그대로 유지합니다.
- 앱이 꺼져 있을 때와 이미 열려 있을 때 모두 동일하게 처리합니다. 화면이 준비되기 전에 도착한 알림의 이동 대상은 준비될 때까지 유지합니다.
- 예산·테스트 알림에도 앱 열기를 연결합니다. 예산 알림은 예산 화면, 결제 확인은 기존 결제 입력 화면으로 연결합니다. 확인 동작만으로 실제 결제 내역을 자동 추가하지 않습니다.
- ‘1시간 뒤’로 미룬 알림도 누르면 해당 알림만 사라집니다.
- 업데이트 또는 앱 시작 시 이미 떠 있는 이전 알림의 누락된 연결을 보완합니다. 기존 문구·시각을 유지하고 다시 소리 내지 않도록 갱신합니다. 오래된 제조사 알림 형식을 처리하지 못해도 앱 시작은 계속됩니다.
- 알림을 읽었다고 전체 알림 설정을 끄거나 전송 이력을 지우지 않습니다. 다음 3일 전·1일 전 및 이후 갱신·종료일 알림은 유지합니다.

검증: 앱 단위67개, 실제 운영 알림 보조 코드를 Android API 대역으로 실행한 Java 검사, 기존 달력 계산 Java 검사, 실제 APK 자산과 Android 허용 목록·MIME·CSP를 적용한 시작 검사, 브라우저 알림 연동 검사. 정확한 알림만 제거, ID 충돌 방지, 중복 확인, 이전 알림 복구, 읽지 않은 알림 유지, 다음 3일/1일 이벤트, 기존 비용·분류·결제 기록 보존을 확인했습니다. Android 실기기 실행과 구분합니다.

기존 패키지와 업데이트 서명을 유지합니다. 앱 삭제·데이터 초기화 없이 업데이트하세요. 다른 앱의 알림을 읽는 기능이나 새 권한은 추가하지 않습니다.
