## 앞으로 실패하면

오류를 SQLite에 저장하고 원인별 다음 시도 시각을 정한다. 일시적인5xx/시간초과는 제한 재시도하고, 403/CAPTCHA는 길게 쉰다. 실패한 검색 경로가 있어도 RSS·공식 페이지·사이트맵·공개 목록과 다른 서비스 조사는 계속한다. 파싱 규칙을 올렸을 때 미확인 가격 목표는 한 번 다시 검토한다. 접근 실패나 후보를 할인 확정으로 바꾸지 않는다.

앱 설정 → 혜택 데이터 → 자동 조사 결과 보기에서 실패 사유·다음 조사 시각·검색 경로·통화별 요금 커버리지를 확인할 수 있다. 모든 사이트의 성공을 보장하는 기능은 아니다. Google/Naver 공식 API는 저장소 소유자의 인증키 설정 후 사용할 수 있으며, 현재 미설정 상태의 대체 경로도 작동한다.

## 달러·연간 비용 비교

- KRW 외 USD·EUR·GBP·AUD·CAD의 확인된 공식 요금을 지원한다. 현재 외화 플랜은 현재 이용 플랜 ID를 연결해야 하며 원화 입력 금액으로 외화 플랜을 추측하지 않는다.
- 같은 통화·지역·세금·납부 기간의 동등/상위 플랜이면 표시요금 차이를 계산한다. 외화의 공식 표시요금과 실제 원화 청구액은 구분한다.
- 연간 요금은 실제 표시된 연간 총액과 월 환산을 구분하고 선결제를 표시한다. 월 환산 숫자를 곱해 근거 없는 연간 요금을 만들지 않는다.
- 통화나 과금 조건이 다르면 환율 없이 절감액을 계산하지 않는다. 이 경우에도 입증된 기능 개선이 있을 때만 기능 대안을 표시한다.
- 현재 플랜은 추천 → 비교 → 구독 점검·절약 관리에서 연결한다. 대안의 가격·기능은 서버가 조사한다.
- 기존 실제 지출·결제 원장은 원래 원화 기록을 유지한다. 외화 비교 가격이 개인 지출에 자동 입력되지 않는다.
