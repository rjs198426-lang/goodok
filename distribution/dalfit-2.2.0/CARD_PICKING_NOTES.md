# 달핏 2.2.0 · 빌드 56 — 카드피킹

- 카드피킹을 독립 탭으로 추가
- 카드사별 마지막 이용일·보유 여부·이전 행사 혜택 수령일을 직접 기록
- 기본 6개월 미사용 기준을 1~36개월로 설정, 달력 개월 수로 계산
- 이용일부터 N개월 또는 이용 월 이후 N개월 전체 경과 기준 선택
- 이전 혜택 재수령 제한 기간과 미보유 조건을 함께 확인
- 기록 기준 충족·기간 대기·기록 확인 필요·보유 조건 확인 상태 구분
- 확인 예정일 7일 전·1일 전·당일 알림, 알림을 누르면 해당 카드사 이력으로 이동
- 오늘 사용 기록으로 미사용 기간 재계산, 개별 알림만 갱신하고 기존 납부 알림 보존
- 카드사 기록 추가·수정·삭제, 백업·복원·자동 백업 및 전체 삭제 연결
- 기존 월간 비용·실제 결제·예산·분류·알림 유지; 카드 기록을 실제 지출로 만들지 않음

## 계산 기준

직접 입력한 이력과 개인 설정 기준의 계산입니다. 행사 참여 또는 캐시백 지급을 확정하지 않습니다. 행사 기준일, 카드사 전체 이용 내역, 가족·체크카드 포함 여부, 보유·해지 및 혜택 수령 제한은 공식 행사 조건과 대조하세요. 실제 카드 행사 자동 조사와 카드사 이용 내역 연동은 이 버전에 포함하지 않습니다.

미사용 기간은 180일로 바꾸지 않습니다. 날짜 기준의 말일은 대상 월 말일로 맞춥니다. ‘이용 월 이후 N개월’은 다음 달부터 N개월 전체가 지난 다음 1일입니다. 혜택 수령 제한을 함께 설정하면 두 기간 중 나중 날짜를 확인일로 사용합니다. 재수령 제한 0은 그 조건을 계산하지 않는다는 뜻입니다. 확인하지 않은 이용·혜택 이력을 없었던 것으로 처리하지 않습니다.

알림은 앱 알림·기기 권한이 켜져 있어야 합니다. 기기 절전 등에 따라 실제 전달 시각이 늦어질 수 있습니다. 기간이 불명확하거나 설정한 미보유 조건 확인이 필요한 항목은 알림을 예약하지 않습니다. 카드번호·비밀번호·카드사 로그인은 입력하지 않으며 기록은 이 기기에 저장됩니다. 사용자가 선택한 외부 백업에는 카드사 이력이 포함됩니다.

검증: 단위 79개, 기존 브라우저 12개 묶음, 월간 결제월·날짜 목록·카드피킹 검사, 실제 APK 자산·내부 접근 규칙을 적용한 시작 검사, Java 알림 계산 및 Android API 대역을 이용한 알림 동작 검사. Android 실기기 실행 검사는 수행하지 않았습니다. release 빌드·lint 오류 0개. 기존 패키지와 서명을 유지합니다.
