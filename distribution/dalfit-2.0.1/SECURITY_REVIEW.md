# 달핏 2.0.1 · 빌드 46 보안 대응 기록

2026-10-28 한국시간, 사용자가 2.0.0 APK에 대해 Google Play 프로텍트에서 유해/위험 앱 설치 차단이 나타났다고 보고했다. 정확한 탐지명·기기 화면·Google 상세 사유는 아직 확보하지 못했다. 원인이나 오탐 여부를 확정하지 않는다. 차단을 무시하거나 보호 기능을 끄는 설치 방법은 안내하지 않는다.

## 수정

- 다른 앱의 알림을 읽는 `NotificationListenerService` 선언·구현과 해당 접근 설정/출처 선택 기능을 제거했다. 이것이 판정 원인이라는 증거는 아직 없다.
- 기존 출처 허용 설정을 비활성화한다. 이미 기기에 저장된 과거 검토 원문은 실제 지출로 자동 변환하지 않고 기존 검토함에서 확인·폐기할 수 있게 보존한다.
- 사용자 자신이 선택한 이미지·공유 텍스트·수동 입력과 달핏 자신의 결제/예산 알림은 유지한다.
- 거래·예산·목표·사용자 분류·백업·패키지와 업데이트 서명을 유지한다. 기존 기록 삭제나 새 패키지 설치를 요구하지 않는다.

## 서명 및 한계

기존 설치 호환 때문에 기존 인증서(CN=Android Debug)를 계속 사용한다. 앱 빌드의 `debuggable`은 false지만 서명 자체는 개발용 인증서다. 앞선 ‘정식 버전’ 안내는 Google 심사·개발자 확인을 마쳤다는 의미로 사용할 수 없다. 운영용 서명 전환은 데이터 백업과 업데이트 호환 계획을 별도로 준비해야 한다. 인증서 변경만으로 유해 판정이 해제된다고 주장하지 않는다.
