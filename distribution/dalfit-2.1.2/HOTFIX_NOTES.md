# 달핏 2.1.2 · 빌드 50 — 업데이트 후 시작 오류 수정

2026-10-31 한국시간 기준.

2.1.1에 추가한 `icons.js`, `bundled_icons.js`가 APK에는 들어 있었지만 Android WebView 내부 파일 허용 목록에서 빠져 있었다. 이 때문에 시작 모듈의 의존성 로딩이404로 중단되어 빈 화면 또는 탭 미동작이 발생할 수 있었다. 새 카테고리 SVG9개도 동일하게 누락됐다.

허용 목록에 해당11개 파일과 올바른 MIME을 추가했다. 기존 내부 주소 제한과 CSP는 유지한다. 내부 화면 파일은 캐시를 재사용하지 않고 현재 설치된 패키지에서 읽으며, 비용·결제·사용자 분류를 저장하는 로컬 저장소는 삭제하지 않는다.

기존 일반 HTTP 브라우저 검사는 Android의 별도 파일 허용 목록을 적용하지 않아 이 문제를 놓쳤다. 이번부터 모든 웹 자산과 시작 모듈 의존성이 Android 허용 목록 및 MIME과 맞는지 단위 검사하고, 실제 APK의 자산을 실제 Java 코드의 허용 목록·MIME·CSP로 제공하는 브라우저 검사를 추가했다. 수정 전 APK에서 차단을 재현하고 같은 프로필의 기존 기록을 유지한 채 수정 APK 자산으로 전환해 시작·탭4개·추가 화면·설정 버전·아이콘9개를 확인한다. 이는 실제 Android 기기 실행과 구분한다.

기존 패키지 `kr.goodok.note`와 업데이트 서명을 유지한다. 앱을 삭제하거나 데이터를 초기화하지 않고 새 APK를 덮어 설치한다. 다른 앱 알림 읽기 권한을 추가하지 않는다.
