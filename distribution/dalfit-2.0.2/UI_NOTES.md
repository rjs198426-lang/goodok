# 달핏 2.0.2 · 빌드 47

2026-10-28 한국시간. 사용자가 2.0.1 설치 성공과 함께 설정 화면의 제목·버튼·상태 문구에 여백이 없어 붙어 보이는 사진을 보냈다.

입력·백업·개인정보 카드의 제목을 기존 설정 카드와 동일한 안쪽 여백과 아이콘 헤더에 넣었다. 네 개 버튼은 일정한 폭의 2열 그리드로 배치하고, 버튼 간격과 상하좌우 여백·최소 터치 높이를 확보했다. 긴 버튼 글자는 줄바꿈하고 행 높이는 내용에 맞춰 늘어난다.

카테고리 업데이트 버튼과 확인 상태를 패딩이 있는 별도 상단 영역에 넣고 관리 입력란과 구분선으로 나눴다. 카테고리 관리 제목·입력란의 좌우 정렬을 맞추고, 필드 사이 16px·라벨과 입력란 사이 8px의 간격을 적용했다. 저장 버튼은 폼 전체 폭으로 정리했다. 빈 상태/메시지는 불필요한 빈 줄을 만들지 않는다.

브라우저에서 320×568, 360×640, 390×844, 412×915, 568×320, 1024×768과 텍스트 150%를 확인했다. 제목·버튼·상태의 카드 안쪽 여백, 버튼 간격/동일 폭, 필드 간격, 가로 넘침과 실제 분류 저장을 검증했다. 기존 49개 단위 테스트 및 10개 브라우저 회귀 묶음과 Android release/lint를 확인한다. 실제 Android에서 새 UI를 실행한 검증은 별도다.

기록·계산·백업 형식과 기존 업데이트 인증서를 유지한다. 다른 앱의 알림을 읽는 기능은 재추가하지 않았다. 사용자의 2.0.1 설치 성공 보고는 받았지만 모든 기기의 Play 프로텍트 판정이나 Google의 공식 인증을 주장하지 않는다.
