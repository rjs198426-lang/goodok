# 달핏 2.1.1 · 빌드 49 — 자동 아이콘

- 기존 GitHub 시간별 조사에서 신규 구독의 공식 사이트 아이콘을 함께 확인합니다. 별도의 쓰기 권한이나 새 예약 작업을 추가하지 않습니다.
- 공식 페이지의 아이콘 링크와 공식 사이트 favicon을 우선 확인합니다. Todoist·Webflow는 출처가 명시된 브랜드 원본을 사용합니다.
- 원본을 96px PNG로 정리하고 출처·이미지 해시·확인일을 저장합니다. 앱에서 외부 사이트로 아이콘 요청이나 구독 기록을 보내지 않습니다.
- 아이콘 내용이 바뀌면 당일 카테고리 배포 revision도 갱신됩니다. 앱 실행·복귀·설정의 새로고침에서 반영되며 받은 아이콘은 오프라인에서도 표시됩니다.
- 신규 서비스의 확보된 아이콘을 APK에도 포함합니다. 이미 등록한 서비스도 이름·서비스 키로 찾아 적용합니다.
- 웹·호스팅, 업무 자동화, 보안, 백업, 음성·오디오, 영상 제작, 디자인, 독서·지식, 개발 도구의 전용 카테고리 아이콘 9종을 추가했습니다.
- 카테고리 이름을 바꾸어도 원래 분류에 맞는 아이콘을 유지합니다. 사용자 분류·실제 금액·납부일·백업 형식은 유지합니다.
- 수집 실패 시 마지막 정상 아이콘을 보존하고 재시도합니다. 확보되지 않은 브랜드를 공식 로고처럼 생성하지 않고 이니셜로 표시합니다.

검증: 앱 단위62개, 서버 단위64개, 브라우저12개 회귀 묶음. PNG 크기·형식 제한, 실행 가능한 SVG 차단, 원본 재인코딩, 갱신·오프라인·잘못된 아이콘 수신·분류 이름 변경·기존 실제 금액 보존·화면4종을 확인했습니다. 실기기2.1.1 실행은 별도 확인이 필요합니다.

기존 패키지와 업데이트 서명을 유지합니다. 다른 앱 알림 읽기를 재추가하지 않았습니다. 기존 앱을 삭제하지 않고 업데이트하세요.
